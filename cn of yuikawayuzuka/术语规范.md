# 术语规范（翻译时必须遵守）

本文件是本汉化模组的**翻译依据**，新增任何翻译前先读这里。

---

## 一、保留原文不译

### 1.1 缩写类
缩写一律保留原文，不音译、不意译：

| 类别 | 示例 |
|---|---|
| 游戏机制 | `EVA`、`IVA`、`RCS`、`SAS`、`TWR`、`dV`、`AoA`、`ISP` |
| 界面/技术 | `HUD`、`GUI`、`UI`、`RPM`、`DPAI`、`MJ`、`KER` |
| 单位与规格 | `LF`、`Ox`、`MP`、`EC`、`HS-50`、`5m`、`2.5m` |
| 模组缩写 | `TAC`、`KIS`、`KAS`、`EL`、`CRP`、`OPM`、`JNSQ`、`B9` |
| 天体缩写 | `GNSS`、`LEM` |

> 依据：KSP 官方中文即写作「进行EVA实验」「自动EVA已关闭」。

### 1.2 模组名与厂商名
**模组名**保留原文：`Endurance`、`Benjee10`、`Near Future`、`Waterfall`、`DeepFreeze`、`KSPWarpDrive`

**厂商名**按 KSP 官方惯例**意译**：
- `C7 Aerospace` → C7航天部门
- `Rockomax` → 极限火箭集团
- `Kerbodyne` → 坎波丁
- `Probodobodyne` → 探测机器人公司

### 1.3 星球与天体名
**星球名保留原文**，不音译：`Kerbin`、`Mun`、`Minmus`、`Duna`、`Jool`、`Eve`、`Tekto`、`Slate`、`Sarnus`、`Urlum`、`Neidon`、`Plock`

> 生物群系名（biome）如属于星球专名一部分，同样保留。

## 二、必须汉化

### 2.1 描述性名词（**不是**缩写的专业词，照常翻译）
这类词虽然"显得专业"，但是普通英文名词，必须翻译：

| 原文 | 译法 | 依据 |
|---|---|---|
| `Kerolox` | 煤油液氧 | 推进剂描述性名词 |
| `Hydrolox` | 氢氧 | 同上 |
| `Methalox` | 甲烷液氧 | 同上 |
| `Hypergolic` | 自燃推进剂 | 同上 |
| `Metal` | 金属 | CRP 官方中文 |
| `MetalOre` | 金属矿物 | CRP 官方中文 |
| `RocketParts` | 火箭零件 | CRP 官方中文 |
| `Supplies` | 资源 | CRP 官方中文 |
| `Waste` | 垃圾 | CRP 官方中文 |
| `Water` | 液态水 | CRP 官方中文 |
| `Oxygen` | 气态氧 | CRP 官方中文 |
| `ScrapMetal` | 废金属 | — |
| `HexCan` | 六角罐 | 形状描述 |

### 2.2 零件名（依 KSP 官方中文译名，**不可自创**）

| 英文 | 官方中文 | 零件编号 |
|---|---|---|
| `Terrier` | 猎犬 | LV-909 |
| `Thud` | 砰砰 | Mk-55 |
| `Spark` | 火花 | 48-7S |
| `Poodle` | 贵宾犬 | RE-L10 |
| `Twitch` | 开关 | 24-77 |

> ⚠️ 官方译名与直觉差别很大，务必照抄，不要自行翻译成「小猎犬」「抽搐」「砰」等。

### 2.3 通用英文词汇
`Docking Port` → 对接口；`Rack` → 设备架；`Module` → 舱/模块；
`Container` → 容器；`Recycler` → 回收器；`Nozzle` → 喷口

## 三、格式要求

1. **禁止修改**：键名、`<<1>>` 占位符、`<color=...>` 富文本、`\n` `\"` 转义符、`//` 注释。
2. **单字符键值**（`v`/`y`/`d`/`h`/`m`/`s` 等）保留，可能参与代码格式化。
3. 中文与英文/数字间加空格：「ER-7500 计算机」「128 位」「5m 隔热罩」。
4. 引号使用中文引号「」，与 KSP 官方中文风格一致。
5. 全部文件 **UTF-8** 编码。

---

## 四、译名一致性检查方法

翻译前先查既有译名，避免自创：

```bash
# 原版官方中文词典
grep -n "关键词" "Squad/Localization/dictionary.cfg"

# 各模组自带中文
grep -rn "关键词" "<模组>/Localization/zh-cn.cfg"

# 参考汉化包
grep -rn "关键词" "0000Tinygrox_CNPatches/"
```
